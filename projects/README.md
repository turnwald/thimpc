# Chapter 4 Application Projects

This folder contains the rebuilt application-project finale for the MPC course.

- `project_1_attitude_constraints`: from a simple physical attitude-control problem to constrained linear MPC.
- `project_2_mobile_robot_corridor`: MPC as a predictive correction layer on top of a nonlinear mobile-robot tracking controller.
- `project_3_learning_safety_filter`: learning an MPC expert with a lightweight NumPy policy and a visible CBF-QP safety filter.

The slides introduce the engineering context. The notebooks recap that context briefly and then focus on MPC design, constraints, prediction, and closed-loop interpretation.
